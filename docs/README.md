## 📖 Documentation Standards

All documentation follows these principles:

1. **Truth**: Documentation must match the codebase
2. **Clarity**: Clear, actionable, and well-organized
3. **Completeness**: Cover all aspects without redundancy
4. **Currency**: Regularly updated to reflect current state
